# Public fork notes

This branch is a clean, publication-ready reconstruction of a Ren'Py fork.
It is based on upstream commit `7d01cf5cf4392fa3d2cb1f29448958ad48b83abc`.
The custom history was intentionally squashed so private build keys, generated
integrity tables, and commercial SDK binaries are not present in Git history.

## Main changes

- RPAE-2.0 AES-256-CTR encrypted archives and build-time key injection.
- Trusted-script and Python bytecode integrity checks for encrypted archives.
- Audio/video seeking, looping, end-of-stream tracking, and safer audio-driver
  fallback behavior.
- FFmpeg hardware-decoding integration used with the companion build fork.
- Image decode/prediction and opaque-texture upload optimizations.
- Borderless fullscreen support on Windows.
- Resource-type-aware language selection for images, audio, and text.
- Preference/default initialization and execution lifecycle improvements.
- Pitch-preserving voice and movie playback speed, including live speed
  changes for silent movies and browser playback-rate handling.
- YUV video rendering and reduced voice-related rendering/audio idle stalls.
- Startup windows are revealed after the first presented frame.
- Native system cursors and Cubism Core 5 R5 render-order compatibility.
- Linux ARM/Steam ARM64 packaging and 24-bit PCM WAV regression coverage.

## October 2026 synchronization

Source changes through engine revision
`294bdcb12` were synchronized on 2026-10-01, together with the companion
build fork's changes through `aa1725b`. The runtime now requires FFmpeg's
`libavfilter` for native pitch-preserving media playback. Regression tests
and their synthetic media fixtures are included under `unittests/` and
`testcases/`.

The public commits retain the existing reconstructed history and publication
cleanup. Private generated security data and commercial SDK binaries were
excluded from this synchronization.

## 2026-10-11 synchronization

Engine source through `3abc3712dab2` is synchronized with companion build source
through `539ec99`. This update includes:

- Asynchronous desktop file dialogs and the `renpy.show_file_dialog` API,
  with Windows COM, Linux portal, and macOS native implementations.
- Per-channel live stereo spectrum snapshots and unavailable-device handling.
- Audio underrun sample preservation and corrected Opus seeking.
- Live2D mask reuse and immutable drawable geometry snapshots.
- GL2 draw-state caching, reusable mesh buffers, and shader prediction.
- Matrix cache invalidation and corrected HarfBuzz font setup.
- Matching API documentation, examples, and regression tests.

The public history, fail-closed security placeholders, and license notices
remain intact. Use the companion build fork's `BUILDING.md` for current native
builds; `scripts/nativefiledialog_build.py` is retained as a historical helper.
Commercial SDKs and generated private security data are excluded.

## Security-generated data

The public tree deliberately contains no archive key, executable hash, or
generated bytecode whitelist. `src/aes_rpa.c` fails closed until the private
build injection steps are run. See `SECURITY_BUILD.md`.

VMProtect is optional commercial software and is not included. The companion
public `renpy-build` repository does not enable or link it.

## Licensing

Most existing Ren'Py files retain their MIT notices. The modified
`renpy/pygame/display.pyx`, `display.pxd`, and `mouse.pyx` files retain their
zlib-license notices and are marked as altered. Fork-specific new code is covered by
`CUSTOM_LICENSE.md`. Distributed binaries still contain LGPL dependencies;
see the companion build repository's `SOURCE_OFFER.md`.
