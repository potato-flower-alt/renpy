# Public fork notes

This branch is a clean, publication-ready reconstruction of a Ren'Py fork.
It is based on upstream commit `7d01cf5cf4392fa3d2cb1f29448958ad48b83abc`.
The custom history was intentionally squashed so private build keys, generated
integrity tables, and commercial SDK binaries are not present in Git history.

## Main changes

- RPAE-2.0 AES-256-CTR encrypted archives and build-time key injection.
- Trusted-script and Python bytecode integrity checks for encrypted archives.
- Audio/video seeking, looping, end-of-stream tracking, and safer audio-driver
  fallback behavior.
- FFmpeg hardware-decoding integration used with the companion build fork.
- Image decode/prediction and opaque-texture upload optimizations.
- Borderless fullscreen support on Windows.
- Resource-type-aware language selection for images, audio, and text.
- Preference/default initialization and execution lifecycle improvements.

## Security-generated data

The public tree deliberately contains no archive key, executable hash, or
generated bytecode whitelist. `src/aes_rpa.c` fails closed until the private
build injection steps are run. See `SECURITY_BUILD.md`.

VMProtect is optional commercial software and is not included. The companion
public `renpy-build` repository does not enable or link it.

## Licensing

Most existing Ren'Py files retain their MIT notices. The modified
`renpy/pygame/display.pyx` and `.pxd` files retain their zlib-license notices
and are marked as altered. Fork-specific new code is covered by
`CUSTOM_LICENSE.md`. Distributed binaries still contain LGPL dependencies;
see the companion build repository's `SOURCE_OFFER.md`.
